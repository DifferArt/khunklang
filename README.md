# 🪙 ขุนคลัง

แอปบันทึกรายรับ-รายจ่าย สำหรับคนที่มีรายได้หลายทางและหลายบัญชี
ใช้ได้ทั้งมือถือ (Android) และคอม ข้อมูลเก็บใน **Google Sheet ใน Drive ของคุณเอง**

- แยก **รายรับจริง / รายจ่ายจริง / เงินโอนระหว่างบัญชี** (จ่ายบัตร, เติม TrueMoney, ถอน Payoneer ไม่ถูกนับซ้ำ)
- ปุ่มบันทึกด่วน (กาแฟ, ข้าว, ผ่อนบ้าน, จ่ายบัตร ฯลฯ) — แก้ได้ในชีต `Favorites`
- ติดแท็ก **บ้าน / รถ** แต่ละหลัง แต่ละคัน (เช่น บ้านที่อยู่ / บ้านให้เช่า)
- รองรับ USD (Payoneer, Skrill) และการโอนข้ามสกุลเงิน
- บันทึกตอนไม่มีเน็ตได้ — แอปเก็บไว้แล้วส่งให้เองเมื่อออนไลน์
- เลือกวันที่ย้อนหลังได้
- แนบสลิป / ใบเสร็จ ได้ทุกรายการ (เก็บใน Google Drive)
- 📤 **ส่งบัญชี** รายเดือน: รายงาน Google Sheet + Excel + PDF, สลิปรวม 4 หรือ 6 ใบต่อหน้า A4, Statement ธนาคาร

## โครงสร้าง

```
web/            เว็บแอป (ขึ้น GitHub Pages)
  core.js       ตรรกะกลาง (ใช้ร่วมกับ Apps Script)
  seed.js       บัญชี/หมวด/ปุ่มลัดตั้งต้น (ใช้ร่วมกับ Apps Script)
apps-script/    โค้ดสำหรับวางใน Google Apps Script
  Code.gs       API + เมนูในชีต
  Drive.gs      ไฟล์แนบใน Google Drive + สร้างชุดส่งบัญชี
  Core.gs       สำเนาของ web/core.js   ← สร้างด้วย tools/sync-gas.ps1
  Seed.gs       สำเนาของ web/seed.js   ← สร้างด้วย tools/sync-gas.ps1
tools/          สคริปต์ช่วย (เปิดเซิร์ฟเวอร์ทดสอบ, สร้างไอคอน, sync ไฟล์)
```

## ขั้นตอนติดตั้ง (ครั้งเดียว)

### ส่วนที่ 1 — Google Sheet + Apps Script (ประมาณ 10 นาที)

1. เปิด <https://sheets.new> ตั้งชื่อไฟล์ว่า **ขุนคลัง**
2. เมนู **ส่วนขยาย → Apps Script**
3. ในหน้า Apps Script:
   - ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก [`apps-script/Code.gs`](apps-script/Code.gs)
   - กด **＋ → สคริปต์** สร้างไฟล์ชื่อ `Core` แล้ววางเนื้อหาจาก [`apps-script/Core.gs`](apps-script/Core.gs)
   - สร้างอีกไฟล์ชื่อ `Seed` วางเนื้อหาจาก [`apps-script/Seed.gs`](apps-script/Seed.gs)
   - สร้างอีกไฟล์ชื่อ `Drive` วางเนื้อหาจาก [`apps-script/Drive.gs`](apps-script/Drive.gs)
   - ไอคอนเฟือง ⚙️ **การตั้งค่าโปรเจ็กต์** → เขตเวลา เลือก **(GMT+07:00) Bangkok**
   - กด 💾 บันทึก
4. ด้านบนเลือกฟังก์ชัน **`setup`** แล้วกด **▶ เรียกใช้**
   - Google จะขอสิทธิ์ → เลือกบัญชีของคุณ → ถ้าขึ้น *"Google ยังไม่ได้ยืนยันแอปนี้"* ให้กด **ขั้นสูง → ไปที่ ขุนคลัง (ไม่ปลอดภัย)** → อนุญาต
     (เป็นสคริปต์ของคุณเอง ทำงานในบัญชี Google ของคุณ — ขอสิทธิ์ Drive เพื่อเก็บสลิปและสร้างไฟล์ส่งบัญชี)
   - กลับไปที่ชีต จะเห็นแท็บ Accounts, Categories, Assets, Favorites, Transactions, Settings
5. **Deploy เป็น Web app**: ปุ่ม **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท ⚙️ → **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (แอปมีรหัส API ป้องกันอีกชั้น)
   - กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
6. รีเฟรชหน้าชีต จะมีเมนู **ขุนคลัง → แสดงรหัส API** → คัดลอกรหัสไว้
   > ⚠️ รหัส API = กุญแจเข้าข้อมูลการเงินของคุณ อย่าส่งให้ใคร ถ้าหลุดให้กด **สร้างรหัส API ใหม่**

### ส่วนที่ 2 — นำแอปขึ้น GitHub Pages

1. สมัคร <https://github.com> (ใช้ Gmail เดียวกันได้)
2. สร้าง repository ใหม่ชื่อ `khunklang` แบบ **Public**
   (GitHub Pages ฟรีต้องเป็น Public — ใน repo มีแค่โค้ด **ไม่มีข้อมูลเงินหรือรหัส API**)
3. ในเครื่อง:
   ```bash
   git -C E:/KhunKlang remote add origin https://github.com/<username>/khunklang.git
   git -C E:/KhunKlang push -u origin main
   ```
4. ใน GitHub: **Settings → Pages → Source: GitHub Actions**
   รอ 1–2 นาที แอปจะอยู่ที่ `https://<username>.github.io/khunklang/`

### ส่วนที่ 3 — ติดตั้งลงมือถือ Android

1. เปิดลิงก์แอปใน **Chrome** → เมนู ⋮ → **ติดตั้งแอป** (หรือ *เพิ่มลงในหน้าจอหลัก*)
2. เปิดแอป → แท็บ **⚙️ ตั้งค่า** → ปิด *โหมดทดลอง* → วาง **Web app URL** และ **รหัส API** → **บันทึกและทดสอบ**
3. ทำแบบเดียวกันบนคอม (เปิดลิงก์เดียวกันใน Chrome)

## ก่อนเริ่มใช้จริง: ใส่ยอดยกมา

ในชีต **Accounts** คอลัมน์ `opening_balance` ใส่ยอดเงินของแต่ละบัญชี **ณ วันก่อนรายการแรกที่จะบันทึก**

- ธนาคาร / e-Wallet: ใส่ยอดคงเหลือ (Payoneer, Skrill ใส่เป็น USD)
- บัตรเครดิต / SPayLater / บัตรกดเงินสด: ใส่ **ติดลบ** = ยอดค้างชำระ เช่น `-4200`

ถ้าจะใส่ข้อมูลย้อนหลังตั้งแต่ 1 ม.ค. ให้ใช้ยอด ณ 31 ธ.ค.

## ปรับแต่งเอง (ในชีตได้เลย ไม่ต้องแก้โค้ด)

| ชีต | ทำอะไรได้ |
|---|---|
| Accounts | เพิ่มบัญชี, เปลี่ยนชื่อ, ซ่อน (`active` = FALSE) |
| Categories | เพิ่มเว็บ Stock ใหม่ / หมวดใหม่ (`id` ห้ามซ้ำ), ตั้งบัญชีตั้งต้น (`default_account_id`) |
| Assets | เพิ่มบ้าน/รถ |
| Favorites | เพิ่ม/ลบ/เรียงปุ่มบันทึกด่วน (`sort`) |
| Settings | `usd_thb` อัตราแลกเปลี่ยนที่ใช้สรุปยอด |
| Transactions | ข้อมูลทั้งหมด — ดู/กรอง/ทำ Pivot ได้ (อย่าแก้คอลัมน์ `id`) |

หลังแก้ชีต ในแอปกดปุ่มสถานะมุมขวาบนเพื่อโหลดใหม่

## เมื่ออัปเดตโค้ด Apps Script

วางโค้ดใหม่**ทุกไฟล์** (Code, Core, Seed, Drive) → 💾 → **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้** → ✏️ แก้ไข → เวอร์ชัน: **เวอร์ชันใหม่** → ทำให้ใช้งานได้
(URL เดิมใช้ต่อได้ ไม่ต้องตั้งค่าในแอปใหม่)

**อัปเดตเป็นเฟส 3 ครั้งแรก:** หลังวางไฟล์ `Drive` แล้ว ให้เลือกฟังก์ชัน **`authorizeDrive`** → ▶ เรียกใช้ → อนุญาตสิทธิ์ Google Drive / Docs
(หรือเมนูในชีต **ขุนคลัง → 3) เปิดสิทธิ์ Google Drive**) **ก่อน**สร้างเวอร์ชันใหม่ ไม่อย่างนั้นแนบไฟล์จะขึ้นว่าไม่มีสิทธิ์

## นำเข้า Statement ธนาคาร (PDF)

แท็บ **🏦 บัญชี → 📥 นำเข้า Statement** → เลือกไฟล์ PDF (เลือกหลายเดือนพร้อมกันได้)

- ไฟล์ถูกอ่านในเบราว์เซอร์ (ส่งไปเก็บเฉพาะใน Drive ของคุณเองหลังบันทึก) · ไฟล์ติดรหัสผ่าน → เปิดใน Chrome → Ctrl+P → บันทึกเป็น PDF ก่อน
- แอปตรวจยอดคงเหลือทุกบรรทัดกับใบแจ้ง (✅ = อ่านครบถูกต้อง)
- สีแถบซ้าย: 🔴 ต้องเลือก · 🟡 เดา (ตรวจ) · 🟢 ตามกฎ/แก้แล้ว · 🔵 โอนบัญชีตัวเอง · ⚪ ซ้ำ (ไม่ถูกบันทึก)
- แก้หมวดของชื่อไหน → ใช้กับชื่อเดียวกันทั้งไฟล์ และจำเป็นกฎในชีต `Rules` ไว้ครั้งหน้า
- ใส่ **ชื่อเจ้าของบัญชีภาษาอังกฤษ** ด้วย (เช่น `MR XXXX YYYY`) เพื่อให้รู้ว่าโอนจากธนาคารอื่นเข้าบัญชีตัวเอง
- นำเข้าไฟล์เดิมซ้ำได้ ระบบข้ามรายการที่มีแล้วให้
- รองรับตอนนี้: **กสิกรไทย, กรุงไทย, กรุงเทพ, UOB TMRW, ออมสิน, ttb** (บัญชีเงินฝาก) — ธนาคารอื่นจะเพิ่มเมื่อได้ไฟล์ตัวอย่าง
- ไฟล์รวมหลายเดือน (เช่น 6 เดือน) นำเข้าได้เลย
- บันทึกเสร็จ แอปเก็บไฟล์ PDF ไว้ใน Drive (โฟลเดอร์ `Statement/`) ให้เอง เพื่อใช้ตอนส่งบัญชี

## แนบสลิป / ใบเสร็จ

ในฟอร์มบันทึก (หรือแตะรายการเดิม) → **📎 แนบรูป / PDF** → เลือกได้หลายไฟล์ ถ่ายรูปจากกล้องได้

- รูปถูกย่อในเครื่องก่อนส่ง (ด้านยาว 1600px) ประหยัดเน็ตและพื้นที่ Drive
- เลือกชนิดได้ว่าเป็น **สลิป** หรือ **ใบเสร็จ/บิล** · รายการที่มีไฟล์แนบจะมี 📎
- ไฟล์อยู่ใน Drive โฟลเดอร์ **ขุนคลัง — เอกสาร/สลิปและใบเสร็จ/YYYY-MM** (ข้างไฟล์ชีต) และชีต `Files`
- ต้องออนไลน์ตอนแนบ (รายการบันทึกออฟไลน์ได้ แต่ไฟล์ต้องรอมีเน็ต)

## 📤 ส่งบัญชี (รายเดือน)

หน้าหลัก หรือแท็บบัญชี → **📤 ส่งบัญชี** → เลือกเดือน (ค่าเริ่มต้น = เดือนที่แล้ว)

1. เลือก **ทั้งหมด** หรือ **เฉพาะรายได้คอร์ส** และ **สลิป 4 หรือ 6 ใบต่อหน้า**
2. ตรวจความครบ: Statement ของบัญชีที่มีรายการเดือนนั้น (ยังไม่มี → **⬆️ แนบ PDF**),
   รายรับ-จ่ายที่ยังไม่มีเอกสาร (แตะเพื่อแนบ)
3. กด **สร้างชุดเอกสาร** (1–3 นาที) ได้โฟลเดอร์ `ส่งบัญชี/YYYY-MM` ใน Drive ที่มี:
   - **Google Sheet + Excel + PDF รายงาน**: สรุปรายรับ/รายจ่ายตามหมวด (ไม่รวมเงินโอน), ยอดแต่ละบัญชีต้น-สิ้นเดือน,
     รายการรายรับ / รายจ่าย / โอนระหว่างบัญชี, รายชื่อผู้เรียน — ไม่มีชื่อหรือเลขผู้เสียภาษีบนหัวรายงาน
   - **PDF สลิปและใบเสร็จ** หน้า A4 เรียงตามวันที่ ทุกใบมีป้าย `S-001 · วันที่ · ยอด · หมวด · บัญชี`
     เลข S-xxx ตรงกับคอลัมน์ "เอกสารแนบ" ในรายงาน
   - สำเนา **Statement** และใบเสร็จที่เป็น PDF
4. เปิดโฟลเดอร์ → **แชร์** → ใส่อีเมลนักบัญชี (ผู้มีสิทธิ์อ่าน)

สร้างซ้ำได้ทุกเมื่อ (เช่น แนบสลิปเพิ่ม) ชุดเก่าในโฟลเดอร์จะย้ายไปถังขยะ

## แผนต่อไป

- ✅ **เฟส 2** นำเข้า Statement ธนาคาร (PDF) + กฎจัดหมวด + จับคู่โอนระหว่างบัญชี + กันซ้ำ
- ✅ **เฟส 3** แนบสลิป/ใบเสร็จ (Drive) + 📤 ส่งบัญชีรายเดือน (Sheet / Excel / PDF, สลิป 4–6 ใบต่อหน้า, เฉพาะคอร์ส)
- **เฟส 3 ต่อ** (ยังไม่ทำ)
  - แนบสลิปเก่าทีละหลายไฟล์ จับคู่กับรายการตามวันที่ + ยอดเงินอัตโนมัติ
  - แชร์สลิปจาก K PLUS เข้าแอป → อ่าน QR (กันซ้ำ) + OCR ยอดเงิน
  - ป้าย "ไม่มีใบเสร็จ", ช่องวันหมดประกันสินค้า, อัตราแลกเปลี่ยนจริงของรายการ USD
  - ติ๊กเลือก/เอาออกรายการก่อนส่ง, ป้าย "ส่งบัญชีแล้ว ✓", สลิปเป็นรูป PNG รายหน้าสำหรับ LINE
- **เฟส 4** ปฏิทินบิล + แจ้งเตือน (ผ่อนบ้าน ×2, ผ่อนรถ ×2, ประกัน, ประกันสังคม ×3, บัตร, เตือนรับโฉนด/เล่มคืนเมื่อผ่อนหมด)
- **เฟส 5** Dashboard: รายได้แยกช่องทาง/รายเว็บ, กำไรบ้านให้เช่า, ค่าใช้จ่ายรายรถ
- **เฟส 6** สรุปภาษีสิ้นปี
